# HSC Physics 2026 — Interactive Visual Study Guide

An interactive study website for **NSW HSC Physics (2026)**, built on the **NESA Physics Stage 6 Syllabus (2017)**, Year 12 **Modules 5–8**:

| Module | Title |
| --- | --- |
| 5 | Advanced Mechanics |
| 6 | Electromagnetism |
| 7 | The Nature of Light |
| 8 | From the Universe to the Atom |

It is a static single-page app. There is no login, no server, no AI API and no paid service. Progress is stored only in the browser (`localStorage`).

> **Syllabus note.** Inquiry questions are quoted from the NSW Physics Stage 6 Syllabus (2017) © NSW Education Standards Authority, with attribution. Content dot points are **paraphrased** for revision. Check them against the official syllabus on the NESA website before you rely on them. This is an independent resource, not an official NESA publication.

## Features

- **Module pages (sections A–H):** overview with inquiry questions and outcomes; a syllabus breakdown with a dot-point checklist; concept lessons (what / how / why, maths, diagrams, examples, evidence, HSC focus and misconceptions); formulas with inline calculators; simulations; practical and historical experiments; HSC application; and quick revision with an interactive concept map. Each module also has printable notes (use print / save as PDF).
- **Learning modes:** Standard, Beginner (simpler language), Visual (diagrams and formulas, minimal text) and Exam (concise HSC-standard statements). You can switch at any time without losing progress.
- **Physics Lab:** 41 simulations, including projectiles (with an air-resistance comparison), circular motion, torque, gravitational fields, orbits and Kepler's laws, satellites, escape velocity, an E/B field lab, the motor effect, parallel wires, induction, transformers, motors and generators, a 3D EM wave, the spectrum, spectroscopy, double slit, single slit and grating, polarisation, blackbody radiation, the photoelectric effect, Michelson–Morley, relativity, the Big Bang, H–R diagrams, stellar spectra, nucleosynthesis, cathode rays, Millikan, Rutherford, atomic models, hydrogen spectra, matter waves, the quantum atom, decay, nuclear binding energy, fission/fusion and the Standard Model. Each simulation states whether it is a quantitative model or a conceptual visualisation, with its assumptions and limitations. Animations pause when they are off-screen or the tab is hidden.
- **Formula Centre:** about 66 formulas. Each shows notation, variables, SI units, interpretation, conditions, whether it is on the NESA formulae sheet, a worked example, a calculator that solves for any variable, common errors and a practice question.
- **Rearrange:** predefined rearrangements that are checked numerically, not generated by manipulating strings. Notes cover multiple roots and angle ranges.
- **Units Lab:** unit conversions, SI prefixes, derived units and a dimensional-analysis checker.
- **Problem Solver:** an eight-step tutor (understand → knowns → diagram → formula → rearrange → units → calculate → interpret and verify) covering 18 problem types, with randomised numbers and mistake diagnosis (formula, units, sign, calculation). It also has a custom any-formula mode and lists the problems it does not attempt.
- **Graph Lab:** 17 graph types with labelled axes and units, adjustable parameters, a gradient and area tool, and notes on what the gradient and area mean and on each graph's limitations.
- **Working Scientifically:** skills (validity, reliability, accuracy, errors, uncertainty, linearisation, anomalies, risk) and an investigation builder for 8 investigations. Each investigation has 12 parts: question, hypothesis, variables, equipment, method, risks, expected results, a results table, graphs, analysis, conclusion and limitations. Simulated data is clearly labelled. There is also a data analysis tool with linear regression and standard errors, transforms for linearising data, anomaly flagging (points are flagged, never deleted) and CSV export.
- **Discoveries timeline:** about 36 key discoveries, grouped by theme, showing the evidence for each and how it changed the scientific model.
- **HSC Exam Centre:**
  - Section I multiple-choice and Section II short-answer practice with adaptive difficulty (Beginner / Medium / Hard / HSC).
  - Numeric marking checks the value, unit, sign and tolerance.
  - Written answers are self-marked against indicative criteria and a model answer.
  - A full mock exam runs to the NESA format: 100 marks, 3 h + 5 min, 20 MCQs and 80 marks of short answers.
  - Links to official past papers (these are not reproduced).
- **Progress:** performance by module, subtopic and error type, with recommendations.
- **Flashcards** (Leitner spaced repetition), **bookmarks**, **global search** (Ctrl/⌘ + K or `/`), **syllabus explorer** with a coverage matrix (dot point → lesson, visualisation, formulas, practice), and dark/light themes.

### Honest limits

- Written-response feedback is **self-marking**. Matching keywords cannot reproduce NESA marking, and this site does not claim to.
- Practice questions were written for this site. No copyrighted examination content is reproduced.
- Nuclear content is theoretical and educational only.

## Tech stack

React 18 + TypeScript + Vite, Tailwind CSS, Lucide icons, Framer Motion, Recharts, React Flow (`@xyflow/react`), KaTeX, SVG/Canvas, and Three.js via React Three Fiber (3D EM wave). Physics utilities (`src/lib/physics`) are pure functions, kept separate from rendering and covered by Vitest unit tests.

```
src/
  lib/physics/      pure physics + statistics utilities (and __tests__)
  content/          syllabus, lessons, formulas, questions, solver templates, graphs, history…
  components/       UI kit, graph wrapper, SVG diagrams, simulation shell, layout
  sims/m5..m8/      simulations (lazy-loaded per simulation)
  pages/            routed pages
```

## Getting started

Requirements: Node.js 18 or newer, and npm.

```bash
npm install
npm run dev        # start the dev server at http://localhost:5173
npm test           # run the unit tests (physics solvers, content integrity, solver templates)
npm run typecheck  # TypeScript strict type-check
npm run build      # type-check + production build into dist/
npm run preview    # serve the production build locally
```

## Deployment

The build output in `dist/` is a fully static site. It uses hash-based routing and a relative base path (`base: './'`), so it works from any sub-path without server rewrites.

- **GitHub Pages:** run `npm run build` and publish the `dist/` folder, for example with the `actions/upload-pages-artifact` and `actions/deploy-pages` workflow, or by pushing `dist/` to a `gh-pages` branch.
- **Netlify / Vercel / Cloudflare Pages:** build command `npm run build`, publish directory `dist`.
- **Any static host or a USB stick:** copy `dist/` and open it through a static web server, for example `npx serve dist`.

## Data sources

Constants match the NESA Physics data sheet (for example g = 9.8 m s⁻², G = 6.67 × 10⁻¹¹ N m² kg⁻², c = 3.00 × 10⁸ m s⁻¹). Reference data comes from:

- NIST: CODATA constants and the Atomic Spectra Database
- NASA: planetary fact sheets
- IAEA / AME2020: atomic masses
- ESA, CERN, ANSTO, CSIRO and the Bureau of Meteorology

All sources are listed on the in-app **Data Sheet & Sources** page. Wikipedia is not used as a source.

## Testing and QA

- `npm test` runs 444 unit tests. They cover:
  - kinematics, orbits, fields, induction, optics, relativity, atomic and nuclear calculations
  - every formula rearrangement
  - syllabus coverage (every dot point has a lesson, a visualisation, formula links and practice)
  - question integrity, with numeric answers recomputed independently
  - solver templates across random seeds
  - static diagram references
- Every route and simulation was also checked in Chromium (Playwright) at desktop and mobile widths, in dark and light themes, with no runtime or console errors and no horizontal overflow.
